# Audio credits (recorded samples)

Recorded sound files shipped under `public/assets/audio/`. Everything else in the game's audio is procedurally synthesised in code (`src/audio/`).

Licences accepted: CC0 1.0, public domain, CC BY 3.0 / 4.0. Every licence was checked on the source page itself. Nothing here is NC, ND, Sampling+ or of unknown licence, and there is no copyrighted music. All files were edited (trimmed, faded, loudness-normalised, converted to MP3; per-file changes are listed below).

Summary: 234 files CC0 1.0, 34 files CC BY 4.0, 12 files CC BY 3.0, 1 files Public domain (PD-self), 281 files in total, from 162 source recordings.

Freesound files were taken from the public HQ preview (`cdn.freesound.org/previews/...-hq.mp3`) of each sound, which carries the same licence as the original upload.

## Technical notes

- Format: MP3 (LAME VBR, q4 for one-shots, q5 for long stereo beds), 44.1 kHz. One-shots are mono and ambience beds are stereo. A few positional loops (engine, hums, breathing) are mono.
- Loudness: clips of 3 s or more are normalised to about -16 LUFS integrated (one-shots) or -20 to -23 LUFS (loops). Shorter transients (footsteps, knocks, barks) are measured by max momentary loudness and are effectively peak-normalised: at most 3-6 dB of look-ahead limiting, true peak about -2 to -1 dBTP. The measured values are in `manifest.json` (`lufs`).
- Loops: the tail is equal-power crossfaded into the head, so the file loops sample-accurately. `loopSamples` gives the exact length of each loop at 44.1 kHz. MP3 adds 1105 samples of encoder delay that decoders strip via the LAME header. If a browser's decoded buffer is longer than `loopSamples`, set `loopStart = 1105/44100` and `loopEnd = loopStart + loopSamples/44100`.
- 60 Hz mains recordings (North America) were pitched down by 5/6 so the hum sits on Thailand's 50 Hz / 100 Hz.
- Whispers are reversed so no words are intelligible.
